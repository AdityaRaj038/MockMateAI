**MockMate AI**

MockMate AI is an AI-powered interview platform that conducts real-time one-on-one voice interviews, helping users practice and improve their interview skills in a realistic environment.

🚀 Key Features
🎤 1:1 AI Voice Interview (Core Feature)
    Real-time interactive interview with AI, just like a real interviewer
📄 Resume-Based Questions
    Generates personalized questions based on your resume
📚 Domain-Specific Practice
    Tailored questions for different fields (Web Dev, DSA, etc.)
💡 Suggested Answers & Guidance
    Helps improve responses and preparation
🛠️ Tech Stack
* Frontend: React.js, Tailwind CSS
* Backend: Node.js, Express.js
* Database: MongoDB
* AI: LLM APIs (OpenAI or similar)
